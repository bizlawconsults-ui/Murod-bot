# Бот для рассылок в Telegram

## Что делает
- Любой, кто нажмёт /start, попадает в базу подписчиков (SQLite, файл `subscribers.db`, создаётся автоматически).
- Админ (ты) командой `/broadcast` рассылает сообщение всем подписчикам.
- Если юзер заблокировал бота — он автоматически помечается неактивным и больше не получает рассылки.
- `/stats` — сколько всего подписчиков и сколько активных.

## Установка
```bash
pip install -r requirements.txt
```

## Настройка
Открой `bot.py` и заполни:
1. `BOT_TOKEN` — токен, который выдаёт @BotFather при создании бота.
2. `ADMIN_IDS` — твой числовой Telegram user_id (узнать можно у бота @userinfobot). Можно несколько: `{111, 222}`.

## Запуск
```bash
python bot.py
```
Бот будет работать, пока запущен процесс (long polling). Для постоянной работы 24/7 нужно повесить его на сервер/VPS (например через `systemd`, `pm2`, `screen`/`tmux` или Docker).

## Как рассылать
Есть 2 способа:

1. **Текстом сразу в команде:**
   ```
   /broadcast Привет всем! У нас новая акция 🎉
   ```

2. **Реплаем на любое сообщение** (текст, фото, видео, документ, голосовое и т.д.) — просто ответь на него командой `/broadcast` без текста. Это позволяет рассылать медиа, а не только текст.

## Важные нюансы
- Telegram ограничивает скорость отправки (~30 сообщений в секунду в разных чатах), в коде уже есть пауза между отправками и обработка лимита `RetryAfter`.
- Пользователей, заблокировавших бота, база отмечает как неактивных автоматически — заново нажать /start вернёт их в рассылку.
- База — обычный SQLite-файл, его легко посмотреть любым SQLite-браузером (например DB Browser for SQLite) или выгрузить в CSV при необходимости.
