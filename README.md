# Boostcent Outreach

Telethon-юзербот, который работает **только в группах** и никому не пишет в личку.

1. **Ключевые слова.** Видит в группе сообщение с ключевым словом и отвечает
   на него (reply) в этой же группе на русском или узбекском — по языку
   сообщения. Каждый лид дублируется тебе уведомлением.
2. **Реклама раз в сутки.** Если в группе бот ничего не писал последние
   24 часа (`PROMO_INTERVAL_HOURS`), он один раз публикует обычное рекламное
   сообщение. Язык определяется по последним сообщениям группы. Любой ответ по
   ключевому слову тоже сбрасывает этот 24-часовой таймер.

Тексты: 20 на русском и 20 на узбекском, файл `messages.py` (список `TEXTS`).
Один пул используется и для ответов, и для суточного поста; два раза подряд
в одной группе один и тот же текст не ставится.

## Ключевые слова

| UZ | RU |
|---|---|
| `nakrutk*` (nakrutka, nakrutkasi…) | `накрутк*` (накрутка, накрутку…) |
| `nak` | `нак` |
| `telegram nomer` | `телеграм номер` |
| `akk` | `акк` |

`nak`, `akk` и т.п. ищутся только как отдельные слова. Изменить список:
переменная `KEYWORDS` (через запятую, `*` в конце = любые окончания).

Сообщения с рекламой/продажей («qilib beraman», «продам», «недорого»),
со ссылками, пересланные и длиннее 500 символов пропускаются
(`SKIP_SELLERS=0` отключает фильтр).

## Запуск

1. Заведи **отдельный** Telegram-аккаунт, добавь его в нужные группы.
2. `pip install -r requirements.txt`, создай `.env` (см. `.env.example`),
   `python3 auth.py` → скопируй строку в `SESSION_STRING`.
3. Railway: залей репозиторий, задай переменные из `.env.example`.
   Обязательно `ADMIN_USERNAME` — твой юзернейм, иначе не увидишь лиды.

## Лимиты

- Прогрев по дням (считаются сообщения в группах): день 1–3 — 5–10,
  4–7 — 15–25, 8–14 — 30–45, дальше `TARGET_DAILY_MIN`–`TARGET_DAILY_MAX`.
  `SKIP_WARMUP=1` отключает прогрев.
- Паузы между сообщениями 90–240 с, только в часы
  `ACTIVE_HOUR_START`–`ACTIVE_HOUR_END` по Ташкенту.
- **В одной группе бот пишет максимум 2 сообщения за 24 часа** (ответы и
  реклама вместе, `MAX_POSTS_PER_GROUP_24H`). Лид сверх лимита всё равно
  приходит тебе в уведомлении, но ответа в группе не будет.
- Один человек получает ответ по ключевому слову только один раз.
- В одной группе ответы по ключевым словам не чаще, чем раз в
  `KW_GROUP_COOLDOWN_MIN` минут (по умолчанию 5); лид при этом всё равно
  приходит тебе в уведомлении.
- Ответ на сообщение старше `MAX_LEAD_AGE_HOURS` (по умолчанию 2 ч) не отправляется.
- При первом запуске первые суточные посты размазываются по ближайшим 24 часам,
  чтобы бот не написал во все группы сразу.
- Если в группе нельзя писать (бан, закрытый чат, права) или включён долгий
  slow mode, группа пропускается на `BLOCKED_GROUP_DAYS` дней (по умолчанию 3).
- `EXCLUDE_CHATS` — id или названия групп через запятую, куда писать нельзя.

## Ежедневный отчёт

В `REPORT_HOUR` (по умолчанию 21:00 по Ташкенту) бот присылает тебе сводку за
день: сколько сообщений ушло в группы (ответов и рекламных), сколько лидов
было и сколько из них без ответа, ошибки, дневной лимит по аккаунтам, число
групп и список временно закрытых. `REPORT_DAILY=0` отключает отчёт.

## Состояние

`replied.json`, `groups.json` и `daily_stats.json` раз в 15 минут бэкапятся в
«Избранное» первого аккаунта и восстанавливаются после редеплоя. Очередь в
памяти при рестарте теряется. Старый `dm_sent.json` больше не используется.
